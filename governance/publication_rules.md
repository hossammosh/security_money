# Publication, client confidentiality, and repository security

This repository is PUBLIC. Only publication-cleared material belongs here.

## Never upload
- API keys, GitHub tokens, passwords, authentication cookies, or gh.txt.
- Identity, tax, banking, payment-card, or private contact documents.
- Paid assignment invitations, reports, customer screenshots, app builds, logs, recordings, private URLs, customer identities, or confidential fee offers.
- Unpatched vulnerabilities that have not completed responsible disclosure.

## Paid work and research are separate
Test IO's tester terms, sections 8 and 8.1, cover discoveries, customer information, project descriptions, and fee offers: https://test.io/policies-testers . Do not assume anonymization, aggregation, a local LLM, or a private repository authorizes repurposing. Written permission from relevant rights holders and the platform is required where applicable, followed by appropriate privacy/ethics review.

Do not send confidential paid-testing content to Genspark or any external AI service unless explicitly allowed. Follow project-specific restrictions on AI, automation, proxies, scanning, and collaborators. Functional QA permission is not permission to perform security testing.

## Safe public material
Source-linked platform comparisons; learning notes on own legal labs; original code and permitted assets; synthetic examples clearly labeled synthetic; study protocols; approved consent materials; rights-cleared research results; a complete limitations section.

## Credentials
Credentials must remain outside version control and outside outputs/logs. Additive GitHub operations only; no force pushes or deletion without instruction. Review all staged content for secrets and confidential data before publishing. If a credential is exposed publicly, revoke/rotate it promptly; deleting a file does not remove Git history.

## Responsible research
No testing of real banking, ATM, mobile, or other third-party systems without explicit authorization and scope. No invented evidence. Human-subject data requires consent and the applicable ethics determination. Include AI assistance disclosure required by the selected venue.
